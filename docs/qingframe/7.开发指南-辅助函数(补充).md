## 前言
除了本文罗列的辅助函数，框架本身也自带许多辅助函数，在开发服务时，请尽量使用这些辅助函数，避免重新定义函数造成的代码冗余和定义混淆，框架自带的辅助函数请参考：

+ Laravel6.x：[https://learnku.com/docs/laravel/6.x/helpers/5164](https://learnku.com/docs/laravel/6.x/helpers/5164)
+ DiscuzX：[https://addon.dismall.com/library/](https://addon.dismall.com/library/)
+ 微擎2.x：[https://wiki.w7.com/chapter/35?id=603](https://wiki.w7.com/chapter/35?id=603)



## 公共辅助函数
### error()
该方法用于返回统一格式的报错信息

#### 源码详解
```php
/**
 * 返回统一格式的报错信息
 * @param int $errno 错误编号
 * @param string $message 错误消息
 * @return array 包含errno和message的数组
 */
function error($errno, $message = '') {
    ...
    return array(
        'errno' => $errno,
        'message' => $message
    );
}
```

#### 参数说明
+ `$errno`：错误编号
+ `$message`：错误消息，默认为空字符串

#### 调用示例
```php
$result = error(1, "操作失败");
// 返回：array('errno' => 1, 'message' => '操作失败')
```

### message()
该方法用于在后台任意位置抛出响应，会自动根据请求方式将参数以不同形式返回。

当以`API`或`AjaX`方式请求会直接返回统一格式的`JSON`数据，[查看数据结构](https://www.yuque.com/shenwa/qingru/gm56u4#wNjkT)

#### 源码详解
```php
/**
 * 抛出响应
 * @param string|array $message 响应内容，可以是提醒字符串或者要返回的数据
 * @param string|null $redirect 跳转地址
 * @param string|null $type 抛出类型
 * @return response & print
*/
function message($message, $redirect = '', $type = 'error') {
    //Todo Something
    ......
}
```

#### 参数说明
+ `$message`：抛出内容，可以是提醒字符串或者要返回的数据（数组或对象）
+ `$redirect`：抛出内容后跳转的地址，默认为空
+ `$type`：响应类型，可自定义，常见值为`success`、`error`、`redirect`

#### 调用示例
```php

message("保存成功！", referer(), "success");

```

### strexists()
该方法用于检查字符串中是否包含指定子串

#### 源码详解
```php
/**
 * 检查字符串中是否包含指定子串
 * @param string $string 要检查的字符串

 * @return bool 如果包含返回true，否则返回false
 */
function strexists($string, $find) {
    return \Str::contains($string,$find);
}
```

#### 参数说明
+ `$string`：要检查的字符串
+ `$find`：要查找的子串

#### 调用示例
