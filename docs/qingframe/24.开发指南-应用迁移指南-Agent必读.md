## <font style="color:rgb(15, 17, 21);">前言</font>
<font style="color:rgb(15, 17, 21);">该文档用于引导 AI-Agent 将独立系统或第三方应用</font>**<font style="color:rgb(15, 17, 21);">完整</font>**<font style="color:rgb(15, 17, 21);">迁移为轻如云系统的应用模块，使模块完全适配轻如云系统的运行环境，并且可以借助轻如云开放平台进行分发。  
</font>**<font style="color:rgb(15, 17, 21);">AI-Agent 必须严格遵守本文档的所有规范，并将该规范添加到永久记忆文件，不得自行省略或修改任何强制要求。</font>**

**<font style="color:rgb(15, 17, 21);">如果该文档的最后更新日期晚于当前读取的日期，则需要重新读取此文档以获得最新的规范，建议定期每周检测一次。</font>**

## <font style="color:rgb(15, 17, 21);">步骤</font>
### <font style="color:rgb(15, 17, 21);">生成应用模块骨架</font>
```bash
php artisan make:module your_app '应用名称'
```

<font style="color:rgb(15, 17, 21);">通过以上 Artisan 命令可以快速生成应用模块骨架（存放在 Laravel 项目的 </font>`<font style="color:rgb(15, 17, 21);">addons/</font>`<font style="color:rgb(15, 17, 21);"> 目录下）。该命令的详细说明请参考《16.开发指南-应用模块-规范（内置应用）.md》</font>

<font style="color:rgb(15, 17, 21);">生成骨架后，</font>**<font style="color:rgb(15, 17, 21);">必须</font>**<font style="color:rgb(15, 17, 21);">更新描述文件 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">manifest.json</font>`<font style="color:rgb(15, 17, 21);">，补全应用的详细信息（包括应用名称、版本、作者、依赖等）。详细规范</font>**<font style="color:rgb(15, 17, 21);">必须</font>**<font style="color:rgb(15, 17, 21);">严格参考《16.开发指南-应用模块-规范（内置应用）》</font>

#### <font style="color:rgb(15, 17, 21);">应用升级</font>
当出现以下情况时，必须要<font style="color:rgb(15, 17, 21);">更新描述文件的版本名称（version）和版本号（version_code）来供后台管理面板运行升级：</font>

+ <font style="color:rgb(15, 17, 21);">数据库结构出现变化，数据库迁移文件有更新</font>
+ <font style="color:rgb(15, 17, 21);">需要运行升级文件来实现资源、库文件的移动、复制、解压</font>
+ <font style="color:rgb(15, 17, 21);">其它需要运行应用升级文件的情形</font>

注意：数据库的迁移文件、应用的安装/升级/卸载文件的编写**必须**遵守幂等原则，例如将`Schema::create()`方法用`if(!Schema::hasTable()){}`包裹起来，用`Schema::dropIfExists()`代替`Schema::drop()`等等。

### <font style="color:rgb(15, 17, 21);">数据库迁移</font>
#### 生成迁移文件
```bash
php artisan make:migration create_your_app_users_table --path=addons/your_app/database/migrations
```

<font style="color:rgb(15, 17, 21);">通过以上命令快速生成数据表的迁移文件。</font>**<font style="color:rgb(15, 17, 21);">必须</font>**<font style="color:rgb(15, 17, 21);">在迁移文件中编写：</font>

+ `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">Schema::create('your_table', fn(Blueprint $table))</font>`<font style="color:rgb(15, 17, 21);">：定义表结构</font>
+ `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">Schema::drop('your_table')</font>`<font style="color:rgb(15, 17, 21);">：定义回滚操作</font>

<font style="color:rgb(15, 17, 21);">当你的项目包含多个数据表时，可以将多个表的结构写在同一个迁移文件中（按依赖顺序排列）。所有字段定义</font>**<font style="color:rgb(15, 17, 21);">必须</font>**<font style="color:rgb(15, 17, 21);">使用 Laravel 的</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">Blueprint</font>`<font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">支持的类型，禁止直接写原生 SQL 定义字段。</font>

#### <font style="color:rgb(15, 17, 21);">运行迁移</font>
轻如云系统在安装应用时会自动运行迁移（前提是迁移文件的路径必须正确），如果您需要测试迁移，可以运行以下指令：

```bash
php artisan migrate --path=addons/your_app/database/migrations
```

### <font style="color:rgb(15, 17, 21);">ORM 模型迁移</font>
**<font style="color:rgb(15, 17, 21);">必须</font>**<font style="color:rgb(15, 17, 21);">为所有数据表编写完整的 ORM 模型文件，存放于 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">addons/your_app/app/Models/</font>`<font style="color:rgb(15, 17, 21);">。每个模型文件</font>**<font style="color:rgb(15, 17, 21);">必须</font>**<font style="color:rgb(15, 17, 21);">包含以下内容（若与 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">Illuminate\Database\Eloquent\Model</font>`<font style="color:rgb(15, 17, 21);"> 默认值一致可省略，但建议显式声明）：</font>

+ `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">$fillable</font>`<font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">或</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">$guarded</font>`<font style="color:rgb(15, 17, 21);">：定义批量赋值的字段</font>
+ `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">$incrementing</font>`<font style="color:rgb(15, 17, 21);">：是否自增（默认为</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">true</font>`<font style="color:rgb(15, 17, 21);">）</font>
+ `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">$timestamps</font>`<font style="color:rgb(15, 17, 21);">：是否自动维护</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">created_at</font>`<font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">/</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">updated_at</font>`<font style="color:rgb(15, 17, 21);">（默认为</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">true</font>`<font style="color:rgb(15, 17, 21);">）</font>
+ `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">$casts</font>`<font style="color:rgb(15, 17, 21);">：字段类型转换（如</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">'is_active' => 'boolean'</font>`<font style="color:rgb(15, 17, 21);">）</font>
+ <font style="color:rgb(15, 17, 21);">关联关系方法（如</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">belongsTo</font>`<font style="color:rgb(15, 17, 21);">,</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">hasMany</font>`<font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">等）</font>**<font style="color:rgb(15, 17, 21);">必须</font>**<font style="color:rgb(15, 17, 21);">正确定义，并指定外键、本地键等参数。</font>

**<font style="color:rgb(15, 17, 21);">禁止</font>**<font style="color:rgb(15, 17, 21);">在模型中编写业务逻辑，模型仅用于数据表交互和关联定义。</font>

### <font style="color:rgb(15, 17, 21);">静态服务类迁移</font>
<font style="color:rgb(15, 17, 21);">将某一类业务常用方法集合整理为静态服务类，存放于 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">addons/your_app/app/Services/</font>`<font style="color:rgb(15, 17, 21);">。  
</font><font style="color:rgb(15, 17, 21);">服务类</font>**<font style="color:rgb(15, 17, 21);">必须</font>**<font style="color:rgb(15, 17, 21);">为 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">final class</font>`<font style="color:rgb(15, 17, 21);">，所有方法</font>**<font style="color:rgb(15, 17, 21);">必须</font>**<font style="color:rgb(15, 17, 21);">为 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">public static</font>`<font style="color:rgb(15, 17, 21);">。服务类</font>**<font style="color:rgb(15, 17, 21);">不得</font>**<font style="color:rgb(15, 17, 21);">直接操作请求、Session、Cookie 等外部状态，只接收参数并返回结果。</font>

### <font style="color:rgb(15, 17, 21);">辅助函数迁移</font>
<font style="color:rgb(15, 17, 21);">将应用中使用到、且 Laravel 和轻如云系统未提供的辅助方法统一整理到一个或多个辅助函数文件中，存放于 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">addons/your_app/app/Helpers/</font>`<font style="color:rgb(15, 17, 21);">。  
</font><font style="color:rgb(15, 17, 21);">定义常见名称的辅助函数</font>**<font style="color:rgb(15, 17, 21);">必须</font>**<font style="color:rgb(15, 17, 21);">通过 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">if (!function_exists('func_name'))</font>`<font style="color:rgb(15, 17, 21);"> 包裹，避免重复定义。</font>**<font style="color:rgb(15, 17, 21);">禁止</font>**<font style="color:rgb(15, 17, 21);">在辅助函数中编写复杂业务逻辑。</font>

### <font style="color:rgb(15, 17, 21);">控制器迁移</font>
<font style="color:rgb(15, 17, 21);">将原系统的控制器逻辑迁移为 Laravel 控制器，存放于 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">addons/your_app/app/Controllers/</font>`<font style="color:rgb(15, 17, 21);">。  
</font>**<font style="color:rgb(15, 17, 21);">必须</font>**<font style="color:rgb(15, 17, 21);">遵循以下规则：</font>

+ <font style="color:rgb(15, 17, 21);">所有控制器</font>**<font style="color:rgb(15, 17, 21);">必须</font>**<font style="color:rgb(15, 17, 21);">继承轻如云系统的基类控制器（ </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">App\Http\Controllers</font>`<font style="color:rgb(15, 17, 21);">），以便自动获得权限验证、响应格式等能力；也可以新建一个公共的控制器来继承基类控制器（ </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">App\Http\Controllers</font>`<font style="color:rgb(15, 17, 21);">），然后将所有的应用控制器继承于此控制器，实现一些自定义的控制器通用/常用方法。</font>
+ <font style="color:rgb(15, 17, 21);">控制器方法</font>**<font style="color:rgb(15, 17, 21);">必须</font>**<font style="color:rgb(15, 17, 21);">使用依赖注入获取 Request、Service 等，禁止直接使用</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">$_POST</font>`<font style="color:rgb(15, 17, 21);">、</font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">$_GET</font>`<font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">等超全局变量。</font>
+ <font style="color:rgb(15, 17, 21);">返回抛出响应结果</font>**<font style="color:rgb(15, 17, 21);">必须</font>**<font style="color:rgb(15, 17, 21);">使用轻如云统一响应方法（如 </font>`return $this->success()`<font style="color:rgb(15, 17, 21);">，</font>`return $this->message()`<font style="color:rgb(15, 17, 21);">, </font>`return $this->error()`<font style="color:rgb(15, 17, 21);">），禁止直接 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">return response()->json()</font>`<font style="color:rgb(15, 17, 21);">。</font>
+ <font style="color:rgb(15, 17, 21);">返回视图响应结果</font>**<font style="color:rgb(15, 17, 21);">必须</font>**<font style="color:rgb(15, 17, 21);">使用轻如云应用视图响应方法：</font>`<font style="color:rgb(15, 17, 21);">return $this->moduleView($view, $data)</font>`<font style="color:rgb(15, 17, 21);">，该方法定义于基类控制器 </font><font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">App\Http\Controllers</font><font style="color:rgb(15, 17, 21);">，因此使用该方法的控制器或其父类必须继承于基类控制器，规范如下。</font>
    - <font style="color:rgb(15, 17, 21);">假设</font>`<font style="color:rgb(15, 17, 21);">$view</font>`<font style="color:rgb(15, 17, 21);">的值为 </font>**<font style="color:rgb(15, 17, 21);">app.index</font>**<font style="color:rgb(15, 17, 21);">，则渲染的视图文件为 </font>`<font style="color:rgb(15, 17, 21);">addons/your_app/views/app/index.blade.php</font>`<font style="color:rgb(15, 17, 21);">。</font>
+ <font style="color:rgb(15, 17, 21);">可以在应用内创建 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">custom_routes.php</font>`<font style="color:rgb(15, 17, 21);">文件定义自定义路由规则，编写规范和 </font>`<font style="color:rgb(15, 17, 21);">web.php</font>`<font style="color:rgb(15, 17, 21);"> 一致，自定义路由规则</font>**<font style="color:rgb(15, 17, 21);">必须严格</font>**<font style="color:rgb(15, 17, 21);">遵守 RESTful 规范。</font>

### <font style="color:rgb(15, 17, 21);">视图迁移</font>
<font style="color:rgb(15, 17, 21);">将原系统的</font>**<font style="color:rgb(15, 17, 21);">前端呈现层</font>**<font style="color:rgb(15, 17, 21);">（即视图模板、页面布局、用户界面逻辑）完整迁移到轻如云模块中，确保所有界面能够正常运行并符合轻如云的前端规范。</font>

#### <font style="color:rgb(15, 17, 21);">模板引擎迁移</font>
+ <font style="color:rgb(15, 17, 21);">原系统如使用原生 PHP、Smarty、Twig 等模板引擎，</font>**<font style="color:rgb(15, 17, 21);">必须</font>**<font style="color:rgb(15, 17, 21);">统一转换为 Laravel 的</font><font style="color:rgb(15, 17, 21);"> </font>**<font style="color:rgb(15, 17, 21);">Blade</font>**<font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">模板引擎。</font>
+ <font style="color:rgb(15, 17, 21);">所有视图文件存放在 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">addons/your_app/views/</font>`<font style="color:rgb(15, 17, 21);"> 目录下，按模块、功能划分子目录。</font>
+ <font style="color:rgb(15, 17, 21);">禁止在视图中直接书写 PHP 原生代码（如 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);"><?php ... ?></font>`<font style="color:rgb(15, 17, 21);">），必须使用 Blade 语法（</font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">@if</font>`<font style="color:rgb(15, 17, 21);">, </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">@foreach</font>`<font style="color:rgb(15, 17, 21);">, </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">{{ }}</font>`<font style="color:rgb(15, 17, 21);"> ，</font>`<font style="color:rgb(15, 17, 21);">{!! !!}</font>`<font style="color:rgb(15, 17, 21);">等）。</font>
+ <font style="color:rgb(15, 17, 21);">在视图中输出变量时，</font>**<font style="color:rgb(15, 17, 21);">必须</font>**<font style="color:rgb(15, 17, 21);">要严格根据变量类型和输出场景区分使用 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">{{ }}</font>`<font style="color:rgb(15, 17, 21);"> 和 </font>`<font style="color:rgb(15, 17, 21);">{!! !!}</font>`<font style="color:rgb(15, 17, 21);">。</font>

#### <font style="color:rgb(15, 17, 21);">布局与组件</font>
+ <font style="color:rgb(15, 17, 21);">后台管理布局（layout）建议继承轻如云系统提供的基布局（如 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">@extends('layouts.console')</font>`<font style="color:rgb(15, 17, 21);">），以保持后台风格统一。</font>
+ <font style="color:rgb(15, 17, 21);">重复使用的界面片段（如头部、侧边栏、卡片、表格）建议封装为 Blade 组件或子视图（</font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">@include</font>`<font style="color:rgb(15, 17, 21);"> 或 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">@component</font>`<font style="color:rgb(15, 17, 21);">）。</font>

#### <font style="color:rgb(15, 17, 21);">前端资源引用</font>
+ <font style="color:rgb(15, 17, 21);">视图中如果需要引用应用的 CSS、JS、图片等资源</font>**<font style="color:rgb(15, 17, 21);">必须</font>**<font style="color:rgb(15, 17, 21);">使用 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">addon_asset()</font>`<font style="color:rgb(15, 17, 21);"> ，禁止硬编码路径。</font>
+ <font style="color:rgb(15, 17, 21);">编译后的前端资源</font>**<font style="color:rgb(15, 17, 21);">必须</font>**<font style="color:rgb(15, 17, 21);">存放在 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">addons/your_app/public/</font>`<font style="color:rgb(15, 17, 21);"> 目录</font>

#### <font style="color:rgb(15, 17, 21);">数据传递</font>
+ <font style="color:rgb(15, 17, 21);">控制器传递给视图的数据</font>**<font style="color:rgb(15, 17, 21);">必须</font>**<font style="color:rgb(15, 17, 21);">使用</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">compact()</font>`<font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">或数组形式，并且</font>**<font style="color:rgb(15, 17, 21);">必须</font>**<font style="color:rgb(15, 17, 21);">对输出内容进行转义（Blade 的</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">{{ }}</font>`<font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">已默认转义）。</font>
+ <font style="color:rgb(15, 17, 21);">对于需要输出 HTML 的内容（如富文本），</font>**<font style="color:rgb(15, 17, 21);">必须</font>**<font style="color:rgb(15, 17, 21);">使用</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">{!! $html !!}</font>`<font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">并确保该内容已经过安全过滤（如</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">purify</font>`<font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">或</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">strip_tags</font>`<font style="color:rgb(15, 17, 21);">），禁止直接输出用户输入而未过滤。</font>
