## 接入流程
该服务用于轻如云系统（后台）对接到第三方系统实现自动登录无缝对接。用户（管理员）从轻如云系统跳转到第三方系统时，会在入口URL后拼接单点登录CODE，第三方系统的入口接收到CODE后，需要向接口传回CODE来获取账户信息，并实现自动功能。具体步骤如下：

1. 接收轻如云系统传来的`CODE`
2. 通过云服务接口`sso/auth/users`获取当前账户信息
    1. [获取云服务接口和Secret](#RjwBB)
    2. 使用Secret将接收的CODE[进行签名](#sEv6V)
    3. <font style="color:rgb(53, 53, 53);">通过</font>[单点登录服务接口](#JALBT)
3. 根据[接口返回](#egiB4)的账户信息进行鉴权，可参考如下几种处理方式：
    - 返回`identity`的值为`founder`时表示当前账户是超级管理员身份，可自动登录超管账号或根据情况作其它处理；
    - 将返回的用户名与系统管理员匹配，或者与此前的单点登录记录匹配，并记录本次单点登录；
    - 根据返回的账户信息创建管理员身份，其中`identity`的值为管理用户组，默认值为“default”，表示默认权限组，该字段的值可以在开放平台自定义，使它与系统权限组一一对应。

注意事项：

+ 接口同时会返回`uniacid`，表示当前登录的平台，对于支持多平台（SaaS）的系统，自动登录时可以自动指定对应的平台，也可以根据需求创建新的平台，使用此方式时，应使用`**<font style="color:rgb(53, 53, 53);">masterSecret</font>**`进行接口加签。
+ <font style="color:#DF2A3F;">单点登录入口支持带URL参数，登录时将直接在URL后加上</font>`<font style="color:#DF2A3F;">code=xxxxxx</font>`<font style="color:#DF2A3F;">，不建议包含“#”的链接</font>

第三方入口示例：

1. [自动登录到微擎系统](https://shenwa.coding.net/public/qingrucloud/sso/git/files/demo/demo/sso.php)（V2.7.8及以上的微擎系统可能不适用）
2. 自动登录到Discuz（待发布）
3. 自动登录到人人商城V5（待发布）
4. 自动登录到芸众商城（待发布）



## 实现单点登录
### 1.获取云服务接口地址及验签Secret
+ `**<font style="color:rgb(53, 53, 53);">secret</font>**`<font style="color:rgb(53, 53, 53);">：单个平台的secret，当需要针对SaaS系统下的某个平台做单点登录时使用该secret进行签名验证；例如微擎站点A下的a1平台对接B系统或对接微擎站点B下的b1平台</font>
+ `**<font style="color:rgb(53, 53, 53);">masterSecret</font>**`<font style="color:rgb(53, 53, 53);">：系统的全局secret，当需要针对系统下多个平台通用统一登录入口时使用该secret进行签名验证，例如微擎站点A对接微擎站点B或对接B系统</font>
+ 安装轻如云系统请参考：[https://www.yuque.com/shenwa/qingru/ze9hby](https://www.yuque.com/shenwa/qingru/ze9hby)

### 2.接口数据签名
```php
const SsoSecrect = '7fa1b268fxxxxxxxxxxxxxxxfa4652e';	//验签Secret

function genSignature($data) {
    // 对参数进行升序排序
    ksort($data);
    // 将参数连接起来
    $dataString = http_build_query($data, '', '&');
    // 使用HMAC-SHA256算法生成签名
    $data['sign'] = hash_hmac('sha256', $dataString, SsoSecrect, false);
    return $data;
}
```

#### 请求参数
| 参数 | **<font style="color:rgba(24, 24, 25, 0.7);background-color:rgb(249, 249, 249);">是否必填</font>** | 类型 | 描述 |
| --- | --- | --- | --- |
| `code` | 是 | String | URL携带的code |
| `time` | 是 | String | 时间戳 |
| `<font style="color:rgb(53, 53, 53);">sign</font>` | 是 | String | 签名 |


:::info
💡 注意 如无法自己获取到 请求URL或者SECRET 请联系相关对接人员获取

sign签名生成规则：将参数进行升序排序后连接起来，然后采用 HMAC-SHA256 算法生成签名,secret需要从平台上获取

:::

```php
/**
 * php生成签名方法示例
 *
 * @param array $data 请求参数列表
 * @param string $secret secret
 * @return string 生成的签名
 */
public function createSignature($data,$secret) {
    // 对参数进行升序排序
    ksort($data);
    // 将参数连接起来
    $dataString = http_build_query($data, '', '&');
    // 使用HMAC-SHA256算法生成签名
    $signature = hash_hmac('sha256', $dataString, $secret, false);
    return $signature;
}
```

#### 请求示例
可以仅传递部分请求参数。

```json
{
    "code": "JSAD08",
    "time": "1688974085",
    "sign": "JSD8FASJHISAID79SFASASD",
}
```

#### 响应
:::tips
**条件**：请求参数合法，并且用户身份校验通过。

**响应示例**：响应会将code解析得到的用户数据返回

:::

```json

{
	"code": 0,
	"message": "请求成功",
	"status": "success",
	"data": {
    "uniacid": 1,
    "uid": 123,
    "username": "admin",
    "identity": "default"
	}
}


```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| `code` | Number | 状态码 |
| `message` | String | 提示 |
| `status` | String | 类型 success:成功，error:失败 |
| `data` | Object | 用户数据 |
| `uniacid` | String | 平台id |
| `uid` | Number | 用户id |
| `username` | String | 用户名 |
| `identity` | String | 身份标识  |


:::info
💡 `identity` 返回 default 则表示默认身份，返回 founder 则代表 超级管理员身份，其他返回均为自定义身份标识

:::

#### 错误响应
:::tips
**条件**：请求数据非法，例如 code 不正确。

响应示例:

:::

```json
{

	"message": "无效的code",
	"status": "error"

```

| 参数 | 类型 | 描述 |
| --- | --- | --- |

| `message` | String | 提示 |
| `status` | String | 类型 success:成功，error:失败 |




#### 状态码字典
| 状态 | 描述 |
| --- | --- |
| 0 | 请求成功 |
| -1 | 缺少secret参数 |
| -2 | 缺少code参数 |
| -3 | 无效code |
| -4 | secret未配置 |
| -5 | 无效的secret |
| -6 | 用户不存在 |

| -9 | 验签失败 |
| -10 | 缺少sign签名 |


### 💡 注意事项
:::info
1.获取到用户信息后，可根据业务进行相应的处理，列如匹配增加用户信息，管理员身份可以直接登录管理员账号等

2.获取到code后，不必每次都请求获取用户信息，可以将code进行储存，在本次会话中，code参数都不会发生变化，直到会话结束

:::



## 内置方法
用于轻如云系统内获取单点登录所需的CODE，三行代码实现从轻如云系统任何位置无缝跳转到第三方系统实现自动登录。

### getCode()
<font style="color:rgb(53, 53, 53);">获取单点登录CODE，用于回传给单点登录服务接口换取当前账户信息；该方法获取的CODE在请求接口时需要使用单个平台secret来进行签名。</font>

```php
/**
* 获取code
* @return  string 查询结果
*/
public function getCode(){
  //Todo something
  $code = ...;
  return $code
}
```

```php
$code = serv("sso")->getCode();		//获取CODE
$url = "https://xxxxxxx.com/web/sso.php?i=1&code=" . $code; //拼接第三方入口链接
// https://xxxxxxx.com/web/sso.php?i=1&code=xxxxxxxxxx
return redirect($url);
```

### <font style="color:rgb(51, 51, 51);">getMasterCode()</font>
<font style="color:rgb(53, 53, 53);">获取单点登录系统CODE（全局）；该方法获取的CODE在请求接口时需要使用全局secret（</font>**<font style="color:rgb(53, 53, 53);">masterSecret</font>**<font style="color:rgb(53, 53, 53);">）来进行签名。</font>

```php
public function getMasterCode(){
    //Todo something
    $code = ...;
  	return $code
}
```

```php
$code = serv("sso")->getMasterCode();
$url = "https://xxxxxxx.com/web/sso.php?code=" . $code;	//拼接第三方入口链接
return redirect($url);
```
