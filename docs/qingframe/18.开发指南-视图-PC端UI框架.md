## 引用公共布局
### 后台管理端
#### 公共布局
管理员端（后台）的公共布局文件位于` /resource/views/layouts/console.blade.php `，该布局引用了系统默认的公共头部模板和公共底部模板，默认加载了 Font-Awesome图标库、<font style="color:#080808;background-color:#ffffff;">Layui 样式库和 JS 库、jQuery 库以及 require.js 库。</font>

参考以下代码即可沿用公共布局。

```html
@extends('layouts.console')

@section('titleExtra')
    &nbsp;&nbsp;<a href="{{ wurl('logs') }}" class="layui-btn layui-btn-primary">@lang('back')</a>
    <!-- 这里可以展示页面顶部内容，会出现在顶部导航栏下方 -->
@endsection

@section('content')
  <div class="container">Hello World.</div>
  <!-- 这里可以展示页面内容 -->
@endsection

```

#### 公共头部模板
在blade模板中引用其中一个公共头部模板

```html
<!-- 只包含 html 起始标签和完整的 head 标签（未包含 body 标签和 html 结束标签） -->
@include('common.headerbase')

<!-- 包含完整头部和顶部导航栏（未包含 body 结束标签和 html 结束标签） -->
@include('common.header')
```

#### 公共底部模板
在blade模板中引用其中一个公共底部模板

```html
<!-- 包含页面底部栏和结束标签（和 common.header 对应） -->
@include('common.footer')

<!-- 只包含 body 结束标签和 html 结束标签（和 common.headerbase 对应） -->
@include('common.footerbase')
```



## 第三方样式库
### TailWind 
在页面添加以下脚本即可使用完整的 TailWind 官方样式库，相关文档请参考：[安装 - TailwindCSS中文文档 | TailwindCSS中文网](https://www.tailwindcss.cn/docs/installation)

```html
<script src="{{ asset('static/tailwind/tailwind3.4.17.js') }}"></script>
<!-- 在HTML中可直接使用 /static/tailwind/tailwind3.4.17.js -->
<script>
  tailwind.config = {
    theme: {
      extend: {
        colors: {
          primary: '#3690C4',
          secondary: '#5260A1',
          dark: '#1A1A1A',
          light: '#F5F7FA'
        },
        fontFamily: {
          sans: ['-apple-system', 'BlinkMacSystemFont', 'Segoe UI', 'Roboto', 'Helvetica Neue', 'Arial', 'sans-serif']
        },
        spacing: {
          '128': '32rem',
          '144': '36rem'
        }
      }
    }
  };
</script>
```

### <font style="color:#080808;background-color:#ffffff;">core.jquery.js</font>（轻如云系统封装辅助JS库）
#### 引用
该 JS 库依赖 jQuery 库

```html
<script type="text/javascript" src="{{ assets('/static/js/core.jquery.js') }}?v={{ QingRelease }}"></script>
```

#### 使用
**发起网络请求（异步）**

```javascript
// 发起POST请求
// Core.post(url, handle, data={}, dataType='json', loading=false)
Core.post('console/account/create', (res)=> {
    console.log(res);
}, {name: "轻如云开放平台"});


// 发起 GET 请求
Core.get('console/account/detail', (res)=> {
    console.log(res);
});


// 发起完整请求
// Core.request(url, method='GET', data={}, dataType='json', handle=function(res){}, loading=false, failed=function(e){});
```

+ `url`：请求目标URL，可以是任何 URL 或项目内的路由
+ `handle`：请求成功回调函数
+ `data`：请求数据
+ `dataType`：请求数据格式（json、html、jsonp）
+ `method`：请求方式（GET、POST、STORE、OPTIONS）
+ `loading`：是否显示加载层，默认为否
+ `failed`：请求失败回调函数

**唤起图片选择器**

```html
<button data-url="/server/storage/picker?type=1" data-title="图片选择器" class="layui-btn layui-btn-default" type="button" onclick="Core.StoragePicker(this);">选择图片</button>

<script type="text/javascript">
  // Core.StoragePicker(Elem, multi=false, CallBack=false);
</script>
```

+ `Elem`：按钮绑定元素
+ `multi`：是否开启多选
+ `CallBack`：选择图片成功回调函数
