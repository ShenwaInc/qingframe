<font style="color:rgb(32, 45, 64);">轻如云系统采用 Laravel 框架自带的</font>[缓存系统 Cache](https://learnku.com/docs/laravel/6.x/cache/5160)<font style="color:rgb(32, 45, 64);">，执行安装向导时使用的是文件缓存驱动，向导安装完毕后使用数据库缓存驱动。  
可以使用</font>**<font style="color:rgb(32, 45, 64);">Cache</font>**<font style="color:rgb(32, 45, 64);">来处理缓存</font>

## <font style="color:rgb(32, 45, 64);">常用方法</font>
### <font style="color:rgb(32, 45, 64);">读取缓存</font>
```php
$value = Cache::get('key');
//指定默认值
$value = Cache::get('key', 'default'); 
```

### <font style="color:rgb(32, 45, 64);">判断缓存是否存在</font>
```php
if (Cache::has('key')) {
  //Todo something
} 
```

### <font style="color:rgb(32, 45, 64);">写入缓存</font>
```php
//长期缓存
Cache::put('key', 'value'); 
//指定缓存时长
Cache::put('key', 'value', 3600); 
```

### <font style="color:rgb(32, 45, 64);">删除缓存</font>
```php
Cache::forget('key'); 
```

### <font style="color:rgb(32, 45, 64);">清空缓存</font>
```php
Cache::flush();
```

### 重建缓存
```php
CacheService::flush();
```



## <font style="color:rgb(32, 45, 64);">系统缓存KEY</font>
<font style="color:rgb(32, 45, 64);">为了避免开发时自定义的KEY与系统设置的KEY冲突造成缓存数据混淆，所有用于保存系统设置的缓存必须通过</font>`**<font style="color:rgb(32, 45, 64);">CacheService</font>**<font style="color:rgb(32, 45, 64);">::</font>**<font style="color:rgb(32, 45, 64);">system_key()</font>**`<font style="color:rgb(32, 45, 64);">来生成唯一KEY，具体用法如下：</font>

```php
$cachekey = CacheService::system_key('key'); 
//读取缓存
$value = Cache::get($cachekey);
//写入缓存 
Cache::put($cachekey, $value); 
```

<font style="color:rgb(32, 45, 64);">因为系统支持多开，为了解决不同平台的同一类型缓存KEY相同的问题，将系统缓存区分为站点缓存(总站缓存)、平台缓存(每个平台的不同)、模块缓存(每个平台的不同模块)</font>

### <font style="color:rgb(32, 45, 64);">站点缓存KEY</font>
```php
CacheService::system_key('key'); 
```

### <font style="color:rgb(32, 45, 64);">平台缓存KEY</font>
```php
//第二个参数是平台ID(uniacid) 
CacheService::system_key('key',1); 
```
