## 事件广播
微服务的事件广播只需要执行微服务主类的 [<font style="background-color:#f7faff;">Event()</font>](https://www.yuque.com/shenwa/qingru/kh3of6#z6bb8) 方法，该方法可以在模型文件的内置方法或者继承了模型文件的控制内调用。执行后系统内所有监听 <font style="color:#cc0000;background-color:#f7faff;">listener</font> 事件的监听器都会被执行并传输对应数据。

### 方法详解
```php
/**
* 事件广播
* @param string $listener 广播事件名
* @param array|null $data 广播数据
* @param array|null|mixed 服务构造参数
* @return bool 广播结果
*/
public function Event($listener, $data=array(), $param=null){
    ......
    //发送事件广播，将会触发所有监听该事件的微服务
    return true;
}
```

该方法的说明请参考：[https://www.yuque.com/shenwa/qingru/kh3of6#z6bb8](https://www.yuque.com/shenwa/qingru/kh3of6#z6bb8)

### 调用方式
```php
// 微服务主类或者继承该主类的其它代码块内

$this->Event("listener", $data);

// 其它代码块
serv('ucenter')->Event("listener", $data);
```

## 事件响应
微服务需要在`manifest.json`文件指定该服务需要监听的所有事件，同时在微服务的模型文件中定义处理事件的方法。

该方法的详细说明请参考：[https://www.yuque.com/shenwa/qingru/kh3of6#x0n0d](https://www.yuque.com/shenwa/qingru/kh3of6#x0n0d)

```json
{
  "application":{
    "name": "用户服务"
    ......
  }
  ......
  "events": ["storage.remove"],	#监听的事件列表
......
}
```

```php
public function Processor($listener, $data=array()){
  switch ($listener){
      case "storage.remove" : {
          //检测用户头像是否被删除
          $uid = .....;
          if ($uid){
              //如果被删除则替换为默认头像
              $this->UpdateInfo($uid, array('avatar'=>$this->defaultAvatar));
          }
          break;
      }
      default :
  }
  return true;
}
```
