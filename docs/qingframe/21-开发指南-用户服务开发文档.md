## 对外开放接口
### 用户注册接口
:::tips
+ **URL**：`/api/server/ucenter/register`
+ **Method**：`POST`
+ **需要登录**：否
+ **需要鉴权**：否

:::

#### 请求Body
| 参数 | 类型 | 必含 | 说明 |
| --- | --- | :---: | --- |
| `i` | Number | 是 | 平台 |
| `username` | String | 是 | 用户名，必须是邮箱或手机号 |
| `password` | String | 是 | 登录密码 |
| `profile` | Array | 否 | 用户基础资料，结构如下：<br/>+ nickName：昵称<br/>+ gender：性别（0未知、1男生、2女生）<br/>+ avatarUrl：头像URL<br/>+ province：省份名称<br/>+ city：城市名称<br/>+ country：区/县名称 |


#### 返回数据
| 参数 | 类型 | 必含 | 说明 |
| --- | --- | :---: | --- |
| `code` | Number | 是 | 成功返回0，其余返回错误的状态码 |
| `redirect` | String | 是 | 重定向URL |
| `type` | String | 是 | 成功返回`success`，其余为错误的类型 |
| `message` | String | 是 | 成功返回`OK`，其余状态返回错误消息 |
| `data` | Object | 是 | 失败返回空对象，成功时字段结构如下：<br/>+ uid：用户唯一标识<br/>+ groupid：用户组ID<br/>+ token：临时登录令牌<br/>+ nickname：用户昵称<br/>+ avatar：用户头像URL |


#### 请求示例
略

#### 成功响应
略

#### 错误响应
