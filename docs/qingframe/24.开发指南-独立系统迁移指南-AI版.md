## <font style="color:rgb(15, 17, 21);">前言</font>
<font style="color:rgb(15, 17, 21);">该文档用于引导 AI-Agent 将独立系统或第三方应用</font>**<font style="color:rgb(15, 17, 21);">完整</font>**<font style="color:rgb(15, 17, 21);">迁移为轻如云系统的应用模块，使模块完全适配轻如云系统的运行环境，并且可以借助轻如云开放平台进行分发。</font><font style="color:rgb(15, 17, 21);">  
</font>**<font style="color:rgb(15, 17, 21);">AI-Agent 必须严格遵守本文档的所有规范，不得自行省略或修改任何强制要求。</font>**

---

## <font style="color:rgb(15, 17, 21);">步骤</font>
### <font style="color:rgb(15, 17, 21);">1. 生成应用模块骨架</font>
```bash
php artisan make:module your_app '应用名称'
```

<font style="color:rgb(15, 17, 21);">通过以上命令快速生成应用模块骨架。</font>[<font style="color:rgb(57, 100, 254);">查看详细说明</font>](https://www.yuque.com/shenwa/qingru/dae7wpppwv8lhzrz#nGkE8)

<font style="color:rgb(15, 17, 21);">生成骨架后，</font>**<font style="color:rgb(15, 17, 21);">必须</font>**<font style="color:rgb(15, 17, 21);">更新描述文件</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">manifest.json</font>`<font style="color:rgb(15, 17, 21);">，补全应用的详细信息（包括应用名称、版本、作者、依赖等）。</font>[<font style="color:rgb(57, 100, 254);">查看详细规范</font>](https://www.yuque.com/shenwa/qingru/dae7wpppwv8lhzrz#g7ubO)

### <font style="color:rgb(15, 17, 21);">2. 数据库迁移</font>
### 生成迁移文件
```bash
php artisan make:migration create_your_app_users_table --path=public/addons/your_app/database/migrations
```

<font style="color:rgb(15, 17, 21);">通过以上命令快速生成数据表的迁移文件。</font>**<font style="color:rgb(15, 17, 21);">必须</font>**<font style="color:rgb(15, 17, 21);">在迁移文件中编写：</font>

+ `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">Schema::create('your_table', fn(Blueprint $table))</font>`<font style="color:rgb(15, 17, 21);">：定义表结构</font>
+ `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">Schema::drop('your_table')</font>`<font style="color:rgb(15, 17, 21);">：定义回滚操作</font>

<font style="color:rgb(15, 17, 21);">当你的项目包含多个数据表时，可以将多个表的结构写在同一个迁移文件中（按依赖顺序排列）。所有字段定义</font>**<font style="color:rgb(15, 17, 21);">必须</font>**<font style="color:rgb(15, 17, 21);">使用 Laravel 的</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">Blueprint</font>`<font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">支持的类型，禁止直接写原生 SQL 定义字段。</font>

### <font style="color:rgb(15, 17, 21);">运行迁移</font>
轻如云系统在安装应用时会自动运行迁移（前提是迁移文件的路径必须正确），如果您需要测试迁移，可以运行以下指令：

```bash
php artisan migrate --path=public/addons/your_app/database/migrations
```

### <font style="color:rgb(15, 17, 21);">3. ORM 模型迁移</font>
**<font style="color:rgb(15, 17, 21);">必须</font>**<font style="color:rgb(15, 17, 21);">为所有数据表编写完整的 ORM 模型文件，存放于</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">public/addons/your_app/app/Models/</font>`<font style="color:rgb(15, 17, 21);">。每个模型文件</font>**<font style="color:rgb(15, 17, 21);">必须</font>**<font style="color:rgb(15, 17, 21);">包含以下内容（若与</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">Illuminate\Database\Eloquent\Model</font>`<font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">默认值一致可省略，但建议显式声明）：</font>

+ `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">$fillable</font>`<font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">或</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">$guarded</font>`<font style="color:rgb(15, 17, 21);">：定义批量赋值的字段</font>
+ `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">$incrementing</font>`<font style="color:rgb(15, 17, 21);">：是否自增（默认为</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">true</font>`<font style="color:rgb(15, 17, 21);">）</font>
+ `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">$timestamps</font>`<font style="color:rgb(15, 17, 21);">：是否自动维护</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">created_at</font>`<font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">/</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">updated_at</font>`<font style="color:rgb(15, 17, 21);">（默认为</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">true</font>`<font style="color:rgb(15, 17, 21);">）</font>
+ `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">$casts</font>`<font style="color:rgb(15, 17, 21);">：字段类型转换（如</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">'is_active' => 'boolean'</font>`<font style="color:rgb(15, 17, 21);">）</font>
+ <font style="color:rgb(15, 17, 21);">关联关系方法（如</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">belongsTo</font>`<font style="color:rgb(15, 17, 21);">,</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">hasMany</font>`<font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">等）</font>**<font style="color:rgb(15, 17, 21);">必须</font>**<font style="color:rgb(15, 17, 21);">正确定义，并指定外键、本地键等参数。</font>

**<font style="color:rgb(15, 17, 21);">禁止</font>**<font style="color:rgb(15, 17, 21);">在模型中编写业务逻辑，模型仅用于数据表交互和关联定义。</font>

### <font style="color:rgb(15, 17, 21);">4. 静态服务类迁移</font>
<font style="color:rgb(15, 17, 21);">将某一类业务常用方法集合整理为静态服务类，存放于</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">public/addons/your_app/app/Services/</font>`<font style="color:rgb(15, 17, 21);">。</font><font style="color:rgb(15, 17, 21);">  
</font><font style="color:rgb(15, 17, 21);">服务类</font>**<font style="color:rgb(15, 17, 21);">必须</font>**<font style="color:rgb(15, 17, 21);">为</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">final class</font>`<font style="color:rgb(15, 17, 21);">，所有方法</font>**<font style="color:rgb(15, 17, 21);">必须</font>**<font style="color:rgb(15, 17, 21);">为</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">public static</font>`<font style="color:rgb(15, 17, 21);">。服务类</font>**<font style="color:rgb(15, 17, 21);">不得</font>**<font style="color:rgb(15, 17, 21);">直接操作请求、Session、Cookie 等外部状态，只接收参数并返回结果。</font>

### <font style="color:rgb(15, 17, 21);">5. 辅助函数迁移</font>
<font style="color:rgb(15, 17, 21);">将应用中使用到、且 Laravel 和轻如云系统未提供的辅助方法统一整理到一个或多个辅助函数文件中，存放于</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">public/addons/your_app/app/Helpers/</font>`<font style="color:rgb(15, 17, 21);">。</font><font style="color:rgb(15, 17, 21);">  
</font><font style="color:rgb(15, 17, 21);">每个辅助函数文件</font>**<font style="color:rgb(15, 17, 21);">必须</font>**<font style="color:rgb(15, 17, 21);">通过</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">if (!function_exists('func_name'))</font>`<font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">包裹，避免重复定义。</font>**<font style="color:rgb(15, 17, 21);">禁止</font>**<font style="color:rgb(15, 17, 21);">在辅助函数中编写复杂业务逻辑。</font>

### <font style="color:rgb(15, 17, 21);">6. 控制器迁移</font>
<font style="color:rgb(15, 17, 21);">将原系统的控制器逻辑迁移为 Laravel 控制器，存放于</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">public/addons/your_app/app/Http/Controllers/</font>`<font style="color:rgb(15, 17, 21);">。</font><font style="color:rgb(15, 17, 21);">  
</font>**<font style="color:rgb(15, 17, 21);">必须</font>**<font style="color:rgb(15, 17, 21);">遵循以下规则：</font>

+ <font style="color:rgb(15, 17, 21);">所有控制器</font>**<font style="color:rgb(15, 17, 21);">必须</font>**<font style="color:rgb(15, 17, 21);">继承轻如云系统的基类控制器（如</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">Qingru\Controller</font>`<font style="color:rgb(15, 17, 21);">），以便自动获得权限验证、响应格式等能力。</font>
+ <font style="color:rgb(15, 17, 21);">控制器方法</font>**<font style="color:rgb(15, 17, 21);">必须</font>**<font style="color:rgb(15, 17, 21);">使用依赖注入获取 Request、Service 等，禁止直接使用</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">$_POST</font>`<font style="color:rgb(15, 17, 21);">、</font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">$_GET</font>`<font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">等超全局变量。</font>
+ <font style="color:rgb(15, 17, 21);">响应结果</font>**<font style="color:rgb(15, 17, 21);">必须</font>**<font style="color:rgb(15, 17, 21);">使用轻如云统一响应方法（如</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">$this->success()</font>`<font style="color:rgb(15, 17, 21);">,</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">$this->error()</font>`<font style="color:rgb(15, 17, 21);">），禁止直接</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">return response()->json()</font>`<font style="color:rgb(15, 17, 21);">。</font>
+ <font style="color:rgb(15, 17, 21);">路由注册</font>**<font style="color:rgb(15, 17, 21);">必须</font>**<font style="color:rgb(15, 17, 21);">通过</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">public/addons/your_app/routes/api.php</font>`<font style="color:rgb(15, 17, 21);">（或</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">web.php</font>`<font style="color:rgb(15, 17, 21);">）文件定义，并遵守 RESTful 规范。</font>

### <font style="color:rgb(15, 17, 21);">7. 视图迁移</font>
<font style="color:rgb(15, 17, 21);">将原系统的</font>**<font style="color:rgb(15, 17, 21);">前端呈现层</font>**<font style="color:rgb(15, 17, 21);">（即视图模板、页面布局、用户界面逻辑）完整迁移到轻如云模块中，确保所有界面能够正常运行并符合轻如云的前端规范。</font>

#### <font style="color:rgb(15, 17, 21);">7.1 模板引擎迁移</font>
+ <font style="color:rgb(15, 17, 21);">原系统如使用原生 PHP、Smarty、Twig 等模板引擎，</font>**<font style="color:rgb(15, 17, 21);">必须</font>**<font style="color:rgb(15, 17, 21);">统一转换为 Laravel 的</font><font style="color:rgb(15, 17, 21);"> </font>**<font style="color:rgb(15, 17, 21);">Blade</font>**<font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">模板引擎。</font>
+ <font style="color:rgb(15, 17, 21);">所有视图文件存放在</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">public/addons/your_app/resources/views/</font>`<font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">目录下，按模块、功能划分子目录。</font>
+ <font style="color:rgb(15, 17, 21);">禁止在视图中直接书写 PHP 原生代码（如</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);"><?php ... ?></font>`<font style="color:rgb(15, 17, 21);">），必须使用 Blade 语法（</font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">@if</font>`<font style="color:rgb(15, 17, 21);">,</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">@foreach</font>`<font style="color:rgb(15, 17, 21);">,</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">{{ }}</font>`<font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">等）。</font>

#### <font style="color:rgb(15, 17, 21);">7.2 布局与组件</font>
+ <font style="color:rgb(15, 17, 21);">公共布局（layout）</font>**<font style="color:rgb(15, 17, 21);">必须</font>**<font style="color:rgb(15, 17, 21);">继承轻如云系统提供的基布局（如</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">@extends('qingru::layouts.app')</font>`<font style="color:rgb(15, 17, 21);">），以保持后台风格统一。</font>
+ <font style="color:rgb(15, 17, 21);">如果应用需要独立的前端风格，</font>**<font style="color:rgb(15, 17, 21);">必须</font>**<font style="color:rgb(15, 17, 21);">在</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">manifest.json</font>`<font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">中声明独立路由并指定自定义布局，但需注明与轻如云整体风格的差异。</font>
+ <font style="color:rgb(15, 17, 21);">重复使用的界面片段（如头部、侧边栏、卡片、表格）</font>**<font style="color:rgb(15, 17, 21);">必须</font>**<font style="color:rgb(15, 17, 21);">封装为 Blade 组件或子视图（</font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">@include</font>`<font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">或</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">@component</font>`<font style="color:rgb(15, 17, 21);">）。</font>

#### <font style="color:rgb(15, 17, 21);">7.3 前端资源引用</font>
+ <font style="color:rgb(15, 17, 21);">视图中的 CSS、JS、图片等资源</font>**<font style="color:rgb(15, 17, 21);">必须</font>**<font style="color:rgb(15, 17, 21);">使用</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">asset()</font>`<font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">或</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">mix()</font>`<font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">辅助函数生成正确的 URL，禁止硬编码路径。</font>
+ <font style="color:rgb(15, 17, 21);">编译后的前端资源</font>**<font style="color:rgb(15, 17, 21);">必须</font>**<font style="color:rgb(15, 17, 21);">存放在</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">public/addons/your_app/assets/</font>`<font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">目录，并通过</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">mix()</font>`<font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">函数引用版本号（如</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);"><link href="{{ mix('/assets/css/app.css', 'addons/your_app') }}"></font>`<font style="color:rgb(15, 17, 21);">）。</font>
+ <font style="color:rgb(15, 17, 21);">禁止直接引用</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">node_modules</font>`<font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">或未编译的源文件。</font>

#### <font style="color:rgb(15, 17, 21);">7.4 数据传递</font>
+ <font style="color:rgb(15, 17, 21);">控制器传递给视图的数据</font>**<font style="color:rgb(15, 17, 21);">必须</font>**<font style="color:rgb(15, 17, 21);">使用</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">compact()</font>`<font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">或数组形式，并且</font>**<font style="color:rgb(15, 17, 21);">必须</font>**<font style="color:rgb(15, 17, 21);">对输出内容进行转义（Blade 的</font><font style="color:rgb(15, 17, 21);"> </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">{{ }}</font>`<font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">已默认转义）。</font>
