## 下载最新完整源码
1. [点此下载框架完整安装包](https://swarelease.oss-cn-shenzhen.aliyuncs.com/r/master/qingframe-laster-full.zip)
2. 解压到站点根目录
3. 设置站点的运行目录为` /public/ `
4. 设置站点的微静态如下（非Nginx服务器请忽略）：

```nginx
location / {
    try_files $uri $uri/ /index.php?$query_string;
}
```

5. 访问站点域名，按提示运行安装向导，即可完成系统的安装。



## 1 前期准备工作
    1. 已备案域名（未备案域名无法解析到国内服务器，也无法接入公众号或小程序）
    2. 云服务器（配置建议2核4G5M及以上，需开放80、22、443、3000及其它WEB常用端口）
    3. 安装操作系统（建议使用Debian 12、CentOS 7、Ubantu 20及以上版本的Linux）
    4. 安装远程命令行SSH或集成管理面板（如宝塔、WDCP等）



## 2 安装运行环境
    1. Nginx 1.21+（推荐使用）、Apache2.4.0+
    2. PHP 7.2、7.3、7.4
        * PHP必须安装这些拓展**<font style="color:#F5222D;">(需重启PHP)</font>**：**fileinfo**、**exif**
        * PHP必须要确保这些函数没有被禁用**<font style="color:#F5222D;">(需重启PHP)</font>**：**putenv**、**proc_open、symlink、readlink、proc_get_status**
    3. MySQL 5.7+、8.0
    4. Composer 2.0+，查看[安装说明](https://www.yuque.com/shenwa/qingru/yioqay5u5c496veb#kvuEC)
    5. Redis 7（非必须，建议配置Redis缓存）



## 3 详细安装步骤

**Apache（如使用宝塔、WDCP等面板请忽略）**

编辑 vhosts.conf 文件或对应站点的单独 .conf 文件（一般在apache安装目录下的 conf/extra/vhosts.conf 或 conf/vhost/xxxx.conf，其中的xxx为站点域名）

```plain
<VirtualHost *:80>
	ServerName v3.whotalk.cn
	DocumentRoot "d:/wamp/www/whotalkv3/public"
	<Directory  "d:/wamp/www/whotalkv3/">
		Options +Indexes +Includes +FollowSymLinks +MultiViews
		AllowOverride All
		Require local
	</Directory>
</VirtualHost>
```

**Nginx（如使用宝塔、WDCP等面板请忽略）**

```nginx
server
{
    listen 80;
		listen 443 ssl http2;
    server_name v3.whotalk.cn;
    index index.php index.html index.htm default.php default.htm default.html;
    root /www/wwwroot/v3.whotalk.cn/public;
  	
  	....
}
```

##### 3.2.2.3 设置站点PHP版本
1. 创建的站点必须指定`PHP7.2`或者`PHP7.3`、`PHP7.4`
2. 站点所指定的PHP版本必须安装这些拓展(需重启PHP)：fileinfo、exif、SG11
3. 站点所指定的PHP版本必须要确保这些函数没有被禁用(需重启PHP)：putenv、proc_open、symlink

##### 3.2.2.4 生成软链接（迁移必做）
安装或者迁移后如出现无法正常上传附件或上传成功却显示异常的情况，说明迁移过程需要生成附件软链接，具体请参考：[常见问题](https://www.yuque.com/shenwa/qingru/gqea6plg3g4w99c5#NSuzt)

```bash
#  进入站点根目录（具体以您的站点路径为准）
cd /www/wwwroot/yourdomain/
rm -rf ./public/storage
php artisan storage:link
```

### 3.5 系统迁移
**<font style="color:#DF2A3F;">以下步骤缺一不可：</font>**

1. 停止运行当前站点（必须，否则备份过程可能会产生新的数据和文件，导致迁移不完整）
2. 备份站点所有文件和数据
3. 参考上文的步骤创建新的站点和数据库，确保环境一致（PHP版本、MySQL版本、Redis配置、PHP拓展）
4. 导入网站文件到站点根目录
5. 导入数据库到新的数据库（如果数据库名和密码有变更请修改站点根目录下 `.env` 文件中的数据库配置）
6. 参考上文的步骤[配置新站点](#RwHAA)
