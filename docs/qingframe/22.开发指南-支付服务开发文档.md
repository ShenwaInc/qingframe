### 统一收银台（网页端）
#### 跳转收银台
:::tips
+ **收银台地址**：`/app/server/payment/cashier?i=<font style="color:#DF2A3F;">{平台ID}</font>&tid=<font style="color:#DF2A3F;">{内部订单号}</font>`
+ `<font style="color:#DF2A3F;">{平台ID}</font>`：当前平台ID
+ `<font style="color:#DF2A3F;">{内部订单号}</font>`：应用内部自行生成的唯一订单编号

:::

#### 应用内唤起收银台
系统内的任意控制器可以通过` return serv('payment')->cashier($params, $moduleName) `方法返回收银台的视图。

该方法用于H5端（或者APP内的WebView）根据参数自动生成系统订单并返回统一收银台的[视图响应对象](https://learnku.com/docs/laravel/6.x/responses/5140#586a91)，非H5客户端需生成系统订单后调用对应支付平台的下单方法将支付信息返回给客户端SDK唤起支付。

在APP的WebView内，微信商户需要开通H5支付才可使用微信支付。

```php
/**
 * 统一收银台（H5）
 * @param array $params 支付参数（金额amount、订单号tid、商品描述subject）
 * @param string|null $module 订单来源：模块/微服务
 * @return array|bool
*/
public function cashier($params, $module=''){
	$payLog = $this->orderBuild($params, $module);
	......
	return $this->View([
		'payment'=>$payments,
		'paylog'=>$payLog,
		'params'=>$params,
		'member'=>$_W['member'],
		'title'=>'收银台'
	], 'cashier');
}
```

**参数说明**

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `<font style="color:#DF2A3F;">$params</font>` | Array | 订单数据：<br/>+ `tid`：内部订单号，必须<br/>+ `amount`：订单金额，创建时必须<br/>+ `subject`：商品描述，创建时必须<br/>+ `openid`：非必须，微信JS-SDK下单时需要提供<br/>+ `uniontid`：外部订单号，创建时如未提供将自动生成<br/>+ `isRecharge`：是否是充值行为，非必须 |
| `<font style="color:#DF2A3F;">$module</font>` | String|NULL | 应用标识或微服务标识，如微服务标识则需要在前面加上`**<font style="color:#DF2A3F;">server:</font>**`<br/>例如：`server:payment` |


**调用示例**

```php
$payment = serv("payment");
if (!$payment->enabled){
	\App\Helpers\message("支付服务暂不可用");
}
$data = array(
	'tid'=>random(12),
	'amount'=>"100.00",
	'subject'=>"测试充值100元",
	'openid'=>$_W['openid'],
	'isRecharge'=>(bool)$params['isRecharge']
);
return $payment->cashier($data, $this->moduleName);
```

**返回说明**

该方法成功时会返回一个[视图响应对象](https://learnku.com/docs/laravel/6.x/responses/5140#586a91)，只需要将该对象返回给Laravel最外层控制器即可进入统一收银台。

如请求失败，会在过程中直接抛出异常。

## 外部接口
### 统一下单（预付费）
:::tips
+ **URL**：`/api/server/run/payment/prepay<font style="color:#DF2A3F;"></font>`
+ **Method**：`POST`
+ **需要登录**：<font style="background:#C0DDFC;color:#00346B">否</font>
+ **需要鉴权**：<font style="background:#C0DDFC;color:#00346B">否</font>

:::

#### 请求参数
| 参数 | 类型 | 必须 | 说明 |
| --- | --- | --- | --- |
| `<font style="color:#DF2A3F;">uniacid</font>` | Number | 是 | 平台ID，1 到 999999 |
| `<font style="color:#DF2A3F;">appid</font>` | String | 是 | 应用的APPID，用于查询应用权限、默认支付配置及分账 |
| `<font style="color:#DF2A3F;">total_amount</font>` | String | 是 | 支付金额，单位为元 |
| `<font style="color:#DF2A3F;">out_trade_no</font>` | String | 是 | 外部唯一订单号，单位为元 |
| `<font style="color:#DF2A3F;">subject</font>` | String | 是 | 商品描述 |
| `<font style="color:#DF2A3F;">notifyUrl</font>` | String | 是 | 支付结果通知地址 |
| `<font style="color:#DF2A3F;">payment</font>` | String | 否 | 默认支付方式，支持`wechat`、`alipay` |


### 微信支付结果通知（异步）
:::tips
+ **URL**：`/api/server/run/payment/notify<font style="color:#DF2A3F;">${uniacid}</font>`
+ **Method**：`POST`
+ **需要登录**：<font style="background:#C0DDFC;color:#00346B">否</font>
+ **需要鉴权**：<font style="background:#F6E1AC;color:#664900">是</font>

:::

#### 请求参数
| 参数 | 类型 | 约束 |
| --- | --- | --- |
| `<font style="color:#DF2A3F;">uniacid</font>` | Number | 1 到 999999 |


#### 请求示例
可以仅传递部分请求参数。

```json
{
    "first_name": "John"
}
```

可以通过传递空字符串来清除数据。

```json
{
    "last_name": ""
}
```

#### 成功响应
:::tips
**条件**：请求参数合法，并且用户身份校验通过。

**状态码：**`200 OK`

**响应示例**：响应会将修改后的用户信息数据返回，一个`id`为 1234 的用户设置他们的姓名后将会返回：

:::

```json
{
    "id": 1234,
    "first_name": "Joe",
    "last_name": "Bloggs",
    "email": "joe25@example.com"
}
```

#### 错误响应
:::tips
**条件**：请求数据非法，例如 fist_name 的长度过长。

**状态码**：`400 BAD REQUEST`

响应示例:

:::

```json
{
    "first_name": "Please provide maximum 30 character or empty string"
}
```

#### 注意事项
:::info
💡 如果用户的用户信息不存在，将会使用请求的数据创建一个新的用户信息。

:::
