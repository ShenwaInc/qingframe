轻如云系统的响应遵循[ Laravel的HTTP响应规范 ](https://learnku.com/docs/laravel/6.x/responses/5140)，本文档对常见类型响应的调用做示例讲解，同时对API接口的响应进行统一约束，并对自带的统一响应方法进行补充说明。

原则上服务提供者可以自己定义自己的接口标准，但为了减少前端开发成本，同时更好的兼容官方的前端框架，本文档提供简易的接口标准规范，强烈建议服务提供者开发设计接口时，直接沿用此规范。





## 抛出响应
在任何继承Laravel 基础控制器（`App\Http\Controllers\Controller`）的控制器内，都可以通过返回 `**$this->message()**` 方法来抛出响应，该方法会根据请求方式将参数以不同形式返回，其中`API`或`AjaX`方式请求会直接返回统一格式的`JSON`数据，[查看数据结构](#wNjkT)

<font style="color:#DF2A3F;">非控制器中的抛出响应请直接使用 </font>`**<font style="color:#DF2A3F;">abort()</font>**`<font style="color:#DF2A3F;"> 或 </font>`**<font style="color:#DF2A3F;">throw new \Exception()</font>**`<font style="color:#DF2A3F;"> 来抛出异常。</font>

```php
class IndexController extends Controller{

  	public function main(){
        //Todo something
        return $this->message('操作成功', wurl('server'), 'success');
    }

    public function settingApi(){
        //Todo something
        return $this->message($settings, "", 'success');
    }


  	public function post(){
        //Todo something
        return $this->message("保存失败，请重试", "", 'error');
    }

}
```

在其它未继承Laravel 基础控制器的位置如需抛出响应可以自行编写公共方法来处理抛出响应，自行编写时请务必注意统一规范。

**在后台控制器中**可以引用公共的辅助函数 `**message()**` 来抛出响应，具体请参考：[辅助函数](https://www.yuque.com/shenwa/qingru/wd4d09#wLdt2)

**在前台控制器中**可以通过辅助函数 `**\App\Helpers\message($message, $redirect, $type)**` 来直接抛出响应并中断运行，参数和后台的公共辅助函数 `message()` 一致。

微服务的抛出响应请参考：[微服务抛出响应](https://www.yuque.com/shenwa/qingru/vnyayi#A1dbV)

## API响应


### 响应结构
| 参数 | 类型 | 说明 | 约束 |
| --- | --- | --- | --- |
| `code` | Integer | 请求状态码，一般默认为0或200 | -9999999至999999 |
| `message` | String | 返回说明，如操作失败的提示信息 | 默认返回 `**OK**` |
| `redirect` | String | 需要跳转的URL地址，一般是弹出提醒后定时跳转，如果参数`type`的返回值是`redirect`则不需要提醒直接跳转 | 255个字符内 |
| `type` | String | 请求结果状态值 | `success``error``redirect``login` |
| `data` | Object | 返回数据 | 非必须 |




### 成功响应（仅响应）
**条件**：操作/请求成功。

**状态码：**`200 OK`

**响应示例**：message字段只返回操作的文字说明（String）

```json
{
    "code":0,
    "message": "操作成功",
    "redirect": "",
    "type": "success",
    "data":[]
}
```



### 成功响应（带返回数据）
**条件**：操作/请求成功。

**状态码：**`200 OK`

**响应示例**：message字段包含了接口请求所需的数据（Object/Array）

```json
{
    "code":0,
    "message":"OK",
    "data": {
        "uid":10086,
        "state":"hFI4DGPp7x9a4ct3pB9kf5XipmDrIWZv=="
    },
    "redirect": "",
    "type": "success"
}
```



### 错误响应
**条件**：操作失败

**状态码**：`200 OK`

响应示例:

```json
{
    "code":-1,
    "message": "Bad Account_Token.",
    "redirect": "",
    "type": "error",
    "data":[]
}
```
