## 前言
轻如云系统基于 Laravel 6.20 开发，本开发指南仅针对新增的特性进行补充，未说明的部分（例如配置、路由、中间件、控制器、请求、session、日志、数据库等）均完全遵守 Laravel 6.20 的规范，相关的技术文档请参考 [《Laravel 6 中文文档》 | Laravel China 社区](https://learnku.com/docs/laravel/6.x/)。



## 开发者模式
### 开启开发者模式
编辑根目录的 .env 文件，在适当位置增加一行如下代码，即可进入开发者模式

```plain
APP_DEVELOPMENT=1
```

#### 命令行一键生成微服务（基础安装包）
在项目根目录使用命令行工具执行如下指令，可以快速生成微服务基础安装包，包含微服务安装包的必要文件和文件夹，有助于快速开发微服务。

```bash
php artisan make:service identity

#其中 identity 为微服务标识，支持英文字母+数字（必须英文字母开头，不支持任何符号）。
```

#### 命令行一键生成应用模块（基础安装包）
在项目根目录使用命令行工具执行如下指令，可以快速生成应用模块基础安装包，包含模块安装包的必要文件和内容示例，有助于快速开发应用模块。[查看详情](https://www.yuque.com/shenwa/qingru/zk44sh8h0hqog7mn)

```bash
php artisan make:module identity
```

#### 单平台（单开）模式
创建好平台后，编辑根目录的` .env `文件，在适当位置增加` APP_UNIACID=<font style="color:#ED740C;">平台ID</font> `即可设为单平台运行模式。

在此模式下，其它平台依然可以正常使用。

#### 停用/启用云服务
在项目根目录使用命令行工具执行如下指令，可以快速开启/停用应用模块的云服务。

```html
php artisan self:maintenance identity state
```

`**identity**`：模块唯一标识

`**state**`：云服务状态，1为停用，0为启用

#### 安装测试版应用/服务
在开发者模式下，您可以优先安装测试版本的应用/服务，但部分应用和服务可能要求您完成开发者认证才能安装体验。



### 关闭开发者模式（生产环境必须）
开发完成并投入线上生产环境时，需要编辑项目根目录的 .env 文件，将如下环境变量改为生产模式

```plain
APP_ENV=production
APP_DEBUG=false
APP_DEVELOPMENT=0
```



## Composer
### 命名空间
开发应用或服务时，需严格遵循 psr-4 原则：

```plain
"autoload": {
    "psr-4": {
        "App\\": "app/",
        "Addons\\": "public/addons/",
        "Server\\": "servers/"
    },
    "classmap": [
        "database/seeds",
        "database/factories"
    ],
    "files": [
        "app/Helpers/core.php"
    ]
}
```

应用模块：

+ 命名空间：Addons\<font style="color:#DF2A3F;">{module}</font>\***
+ 文件路径：/public/<font style="color:#DF2A3F;">{module}</font>/***.php

微服务：

+ 命名空间：Server\<font style="color:#DF2A3F;">{server}</font>\***
+ 文件路径：/servers/<font style="color:#DF2A3F;">{server}</font>/***.php

### Repositories
为了避免不同的应用模块和微服务重复安装 Composer 依赖导致的基础工具包重复带来的项目代码冗余，多个不同应用模块和微服务需要单独安装 composer 工具包时，需要使用Composer的 **<font style="color:#660e7a;">Repositories </font>**工具为项目同步管理这些依赖包。详细规范说明请参考：[composer](https://www.yuque.com/shenwa/qingru/sa6lrl)

### 基础辅助函数
通过配置 `composer.json` 的 `autoload.files` 节点来自动加载基础辅助函数库` app/Helpers/core.php `，具体的辅助函数说明文档请参考：[辅助函数](https://www.yuque.com/shenwa/qingru/fuk9hoqnx5fya0fs)
